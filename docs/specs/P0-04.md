## Objective

กำหนด baseline ที่ reproducible และรองรับร่วมกันสำหรับ runtime, framework, data services และ Docker images ก่อน P0-05/P0-07 สร้าง Compose และ dependency manifests

## In scope

- ตรวจหลักฐาน upstream แบบ official สำหรับ support/compatibility และ image tags
- compatibility matrix พร้อมเวอร์ชัน exact ที่เลือก, support policy และ upgrade ownership
- technology lock manifest ที่เก็บ exact Node, Angular, NestJS, PostgreSQL, Redis และ image references
- Node version file สำหรับ local/tooling baseline
- บันทึก decision, task state และ durable handoff

## Out of scope

- Application scaffolding, package.json/package-lock, dependency installation หรือ library register (P0-07/P0-08)
- Docker Compose, Dockerfile, container pull/build/run หรือ environment variables (P0-05/P0-06)
- Database migration, schema, API หรือ business feature

## Dependencies

P0-01, P0-02 และ P0-03 are DONE. P0-05 and P0-07 must consume this baseline without widening it silently.

## Acceptance criteria

1. Matrix locks one exact supported baseline for Node.js, Angular, NestJS, PostgreSQL, Redis and the required Docker images.
2. The selected Node release satisfies the documented Angular and NestJS requirements.
3. PostgreSQL and Redis use explicit official-image version tags; `latest` and floating major-only tags are prohibited.
4. Lock manifest and `.nvmrc` agree with the matrix; package manager lockfiles remain explicitly deferred to P0-07 because no application package manifests exist yet.
5. Matrix states support/update and major-upgrade policy, image digest capture timing, known compatibility constraints and consuming tasks.
6. No Compose, Dockerfile, application code, dependency install, migration, secret or business feature is introduced.
7. JSON/content/scope/secret assertions and Git diff checks pass; commit/push and clean working tree are recorded.

## Verification commands

- PowerShell JSON parse and task-lock/allowed-path assertions
- Matrix/lock/.nvmrc cross-file content assertions
- Official-source compatibility review recorded in the matrix
- Secret signature and forbidden-artifact scan
- Explicit staged-path allowlist and `git diff --cached --check`
- Git status, commit and remote verification after commit

## Expected evidence / Handoff

Compatibility matrix, lock manifest, exact runtime pin, source links, verification output, decision ID, commit SHA and next action P0-05.
