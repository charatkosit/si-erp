## Objective

นำเอกสารต้นทางเข้าสู่ Git และสร้างโครงสร้าง repository ที่พร้อมรับงาน Phase 0 ถัดไป โดยไม่มี application implementation, Docker Compose, migration หรือ business feature

## In scope

- ตรวจ untracked files และ secret hygiene
- นำ AGENTS.md และเอกสารต้นทาง 4 ไฟล์ใน docs เข้า Git
- สร้าง apps/frontend, apps/backend, packages, infra, docs/ux, docs/specs, docs/qa และ tests โดยใช้ .gitkeep สำหรับ directory ที่ว่าง
- ปรับ README ให้บอกโครงสร้างและลำดับเริ่มงานตาม AGENTS.md
- อัปเดต WORKFLOW_STATE.json, RESUME.md และ DECISIONS.md
- stage เฉพาะ path ที่ระบุและ commit/push เมื่อผ่านเกณฑ์

## Out of scope

- Frontend/Backend source code หรือ business feature
- Docker Compose, container configuration, dependency installation และ migration
- Git workflow/branch protection/PR template ซึ่งเป็น P0-03

## Dependencies

P0-01 DONE และได้รับคำสั่งจาก user/project-owner ให้เริ่ม P0-02 โดยนำ source documents เข้า repository

## Acceptance criteria

1. รายการ untracked ก่อนเริ่มมีเฉพาะ 5 source files ที่กำหนด และตรวจว่าไม่มี secret/ไฟล์ไม่เกี่ยวข้อง
2. เวอร์ชัน PRD v1.7, SDD v1.6, Task List v1.0 และ Operating Model v1.0 ถูกต้อง
3. โครงสร้างที่กำหนดทุก path อยู่ใน Git
4. README อธิบายโครงสร้างและ safe start sequence ตาม AGENTS.md
5. ไม่มี business feature, Docker Compose หรือ migration
6. stage เฉพาะ allowed paths; diff/JSON/structure checks ผ่าน
7. commit/push สำเร็จและ working tree clean

## Verification commands

- git status --short --untracked-files=all
- rg secret-pattern scan เฉพาะ source files โดยรายงานชื่อไฟล์ ไม่แสดงค่าลับ
- ตรวจ version headers ด้วย Select-String
- Test-Path สำหรับทุก directory/.gitkeep
- git diff --cached --check และ git diff --cached --name-only
- ตรวจ WORKFLOW_STATE.json parse/status/lock
- git status --porcelain หลัง commit

## Expected evidence / Handoff

Evidence: inventory, secret/version/structure checks, staged path allowlist, commit SHA, origin/main verification และ clean working tree
Handoff: ปิด P0-02 แล้วเสนอ P0-03 เป็น next task โดยยังไม่เริ่ม
